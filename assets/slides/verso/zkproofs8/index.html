CompPoly

Polynomials are essential in SNARKS.

  • Arithmetization

  • Polynomial IOPs

  • Polynomial commitments

  • FRI

  • ...

There is MORE than just polynomials here, but for polynomials ..

  • Arithmetization — The computation is packaged as polynomials over a finite field

    • (one big constraint system = certain polynomial(s) must be zero on a set of points, or split across “rows” and “wiring”).

  • Polynomial IOPs / PIOPs - JULIAN'S TALK — The prover–verifier protocol is often “send some polynomials, verifier checks a few points or a random combination”

    • (PLONK-style permutation, lookup, custom gates, etc. are all phrased with polynomials).

  • Polynomial commitments (e.g. KZG) - TOBIAS'S TALK — The prover commits to polynomials (KZG, FRI-based, etc.); the verifier only checks a few openings or low-degree — so the object you’re proving about is literally a polynomial (or a small set of them).

  • FRI (in STARKs) — Reed–Solomon views the trace as evaluations of a low-degree polynomial; FRI is a way to test low degree (i.e. “this long vector really comes from a small-degree poly”) without the verifier reading the whole trace.

Univariate Polynomials

namespace slides.Univariate -- Raw polynomials are coefficient arrays def CPolynomial.Raw (R : Type*) := Array R -- the IsCanonical predicate: no trailing zeros def IsCanonical [Zero R] (p : CPolynomial.Raw R) : Prop := ∀ hp : p.size > 0, p.getLast hp ≠ 0 -- Canonical polynomials are a subtype def CPolynomial (R : Type*) [Zero R] := { p : CPolynomial.Raw R // Raw.IsCanonical p } end slides.Univariate

namespace slides.Multivariate /-- The subtype of polynomials with no zero coefficients. -/ def Lawful (n : ℕ) (R : Type*) [Zero R] : Type _ := {p : CPoly.Unlawful n R // p.isNoZeroCoef} /-- A computable multivariate polynomial in `n` variables with coefficients in `R`. -/ abbrev CMvPolynomial (n : ℕ) (R : Type*) [Zero R] : Type _ := Lawful n R end slides.Multivariate

Multivariate Polynomials

namespace slides.Multivariate /-- Polynomial in `n` variables with coefficients in `R`. Internally represented as a tree map from monomials to coefficients. -/ abbrev Unlawful (n : ℕ) (R : Type*) : Type _ := Std.ExtTreeMap (CPoly.CMvMonomial n) R (Ord.compare (α := CPoly.CMvMonomial n)) /-- Check if the polynomial has no zero coefficients. -/ abbrev isNoZeroCoef [Zero R] (p : Unlawful n R) : Prop := ∀ (m : CPoly.CMvMonomial n), p[m]? ≠ some 0 end slides.Multivariate

Multilinear Polynomials

namespace slides.Multilinear /-- `CMlPolynomial n R` is the type of multilinear polynomials in `n` variables over a ring `R`. It is represented by its monomial coefficients as a `Vector` of length `2^n`. The indexing is **little-endian** (i.e. the least significant bit is the first bit). -/ @[reducible] -- coefficient of monomial basis def CMlPolynomial (R : Type*) (n : ℕ) := Vector R (2 ^ n) def CMlPolynomial.mk {R : Type*} (n : ℕ) (v : Vector R (2 ^ n)) : CMlPolynomial R n := v end slides.Multilinear
